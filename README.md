# 澄语 · SillyTavern 角色聊天前端

澄语是一套纯前端、手机 QQ 风格的 LLM 角色聊天界面。完成首次配置后，应用会进入没有常驻设置栏的全窗口聊天模式；角色卡、世界书、预设、API、变量与本地数据统一收进右上角齿轮管理中心。

项目不会预置角色、世界书、预设或对话。首次打开时资料库完全为空，玩家需要导入自己的内容后开始会话。

## 功能

- 导入 SillyTavern V2 JSON 角色卡与带 `chara` 元数据的 PNG 角色卡
- 导入、编辑和启停世界书，支持关键词、位置、顺序、概率与高级规则
- 导入和编辑预设，支持采样参数、系统提示、自定义提示与提示顺序
- 按角色卡、世界书、预设、聊天历史与变量组装请求上下文
- 支持 OpenAI 兼容接口，以及“主模型 + 辅助模型”双接口模式
- 生成期间只显示“对方正在输入”，不会展示分段正文、剧情选项或模型思维过程
- 最终只把角色回复正文写入消息流；原始推理文本不会写入消息元数据，停止或失败时也不会留下半截回复
- 支持停止生成、重新生成、消息编辑、复制、从消息处分支和删除后续内容
- 支持多会话历史、会话重命名、变量检查与手动修改
- 使用 IndexedDB 保存本机资料；备份文件不包含 API 密钥，恢复备份时保留当前设备密钥
- 桌面与手机均采用全窗口单栏聊天布局，包含统一管理中心、站内提示、确认对话框与键盘焦点管理

## 开始使用

```bash
npm install
npm run dev
```

打开页面后按引导完成：

1. 点击右上角齿轮，在“角色卡”中导入 `.json` 或 `.png` 角色卡。
2. 在同一个管理中心按需导入世界书与预设；也可以在界面中新建并编辑。
3. 在“API 与设置”中填写 OpenAI 兼容接口地址、模型名与 API 密钥。
4. 选择角色和预设，创建新会话并开始聊天。

浏览器直接请求模型接口，因此目标服务需要允许当前网页来源进行跨域访问。API 密钥只保存在当前浏览器的 IndexedDB 中；在共享设备上请自行清除本地资料。

## 双接口模式

单接口模式由一个模型完成全部请求。双接口模式可为辅助模型单独配置接口地址、密钥、模型、温度与输出上限，供摘要或辅助处理使用；主模型继续负责角色回复。若辅助接口没有配置完整，应用会明确提示缺少的项目。

## 数据与备份

所有角色卡、世界书、预设、聊天记录、变量与设置均保存在浏览器 IndexedDB。导出备份时会自动移除主、辅助 API 密钥；导入备份不会覆盖当前设备已经保存的密钥。清除全部资料属于不可逆操作，界面会先显示站内确认框。

## 验证与构建

```bash
npm test -- --run
npm run typecheck
npm run build
npm run preview
```

这是前端原型，不包含代理服务器、账号系统、云同步或任何后端实现。设计与实施记录位于 `docs/superpowers/`。
