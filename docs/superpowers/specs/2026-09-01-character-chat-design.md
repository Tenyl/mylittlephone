# 角色聊天前端原型设计说明

## 产品目标

构建一个全中文、移动端优先的网页角色聊天原型。用户可以导入角色卡、世界书和对话预设，并在类似现代中文即时通讯软件的界面中与角色对话。当前版本只实现纯前端体验：消息生成、流式输出、文件解析、状态提醒和持久化均由浏览器本地模拟。

## 范围

- 单用户、单会话、单个当前角色。
- 一份当前角色卡、一份世界书和一个对话预设。
- 纯文本消息，支持发送、停止生成、重新生成、编辑上一条用户消息、删除最近一轮和清空会话。
- 角色卡、世界书和预设通过 JSON 文件导入；导入失败时保留原状态并显示可恢复错误。
- LocalStorage 保存聊天、角色、世界书、预设和用户偏好。
- 不包含账号、群聊、语音、动态、云同步、后端、数据库或真实模型调用。

## 信息架构

桌面端使用三栏应用壳：左侧是功能入口和会话摘要，中间是聊天区域，右侧是当前上下文概况。窄屏只显示聊天主视图，角色、世界书、预设和会话详情以全屏抽屉打开。主要入口始终可从聊天标题栏和左侧导航抵达。

## 核心界面

### 聊天

聊天标题栏显示角色头像、名称、在线或输入状态，并提供上下文面板入口。消息区包含日期分隔、十二条以上的完整演示对话、发送状态、失败状态和返回最新消息按钮。输入区支持 Enter 发送、Shift+Enter 换行、停止生成和附加操作菜单。

模拟回复按字符块流式写入。生成期间发送按钮切换为停止按钮；停止后保留已生成文字并标记为已中断。重新生成会替换最后一条角色消息。用户向上浏览时不强制滚动到底部。

### 角色卡

展示头像、名称、身份、性格关键词、说话风格、背景、用户关系、文件名和导入时间。支持点击选择和拖放 JSON 文件，解析成功后替换当前角色，失败时展示站内错误通知。

### 世界书

展示世界观简介和至少五条具体条目。条目包含标题、关键词、优先级、启用状态、内容和本轮触发状态；支持搜索、展开、启停和 JSON 导入。

### 对话预设

内置“日常陪伴”“沉浸扮演”“剧情推进”三个预设，展示回复长度、主动程度、情感强度、叙事视角、动作描写和手机聊天口吻。切换后下一条消息生效，并出现站内通知。

### 会话详情

展示当前配置、消息数量、模拟上下文占用、创建时间和背景选项。支持导出聊天记录、清空会话和重置角色记忆。破坏性操作使用自定义确认对话框。

## 状态与数据流

`AppState` 保存消息、当前角色、世界书、预设、生成状态、抽屉状态和通知。Reducer 提供可预测的状态变更；持久化层只保存可序列化领域数据，不保存临时弹窗和生成计时器。模拟 LLM 服务读取最后一条用户消息、角色与预设，返回演示回复并通过可取消异步生成器分块输出。

## 视觉系统

- 浅色主界面：雾白背景、冷灰层级、冰蓝主色与蓝紫强调色。
- 字体栈：`Inter Variable`, `Noto Sans SC`, `Microsoft YaHei UI`, `PingFang SC`, sans-serif。
- 使用 4/8px 间距体系、16px 正文、12/14/16/20/28px 字阶。
- 圆角分为 10/16/22/999px，避免所有元素同一圆角。
- 半透明效果只用于应用外壳、抽屉和浮层；消息正文保持足够不透明度和 4.5:1 对比度。
- Phosphor Icons 统一承担导航和操作图标，禁止 Emoji。
- 动画只改变 transform 和 opacity，进入 180–240ms，退出更短；遵循 `prefers-reduced-motion`。

## 响应式与无障碍

- 375px 起可用，768px 展示扩展标题与面板，1024px 以上切换三栏布局，1440px 限制应用最大宽度。
- 移动端输入区与抽屉考虑安全区；按钮最小点击区域 44×44px。
- 所有图标按钮有中文可访问名称，键盘焦点可见，弹窗支持 Escape 关闭并恢复焦点。
- 颜色不作为唯一状态信号；错误、成功和警告均包含图标与中文说明。
- 动态通知使用 polite live region，不抢夺焦点。

## 性能策略

- 功能组件按抽屉粒度拆分，非首屏面板可延迟渲染。
- 消息更新只影响消息流和生成状态，避免整页高频重渲染。
- 文件读取大小限制为 2MB；导入前校验扩展名和 JSON 结构。
- 图片预留宽高；演示头像使用本地 SVG，不依赖外部网络。
- 生产构建按 Vite 路由与依赖分包，避免大型动效库。

## 验收标准

1. 用户可发送消息并看到可停止的流式角色回复。
2. 角色卡、世界书和预设面板有完整演示内容和可操作导入流程。
3. 三个内置预设可切换，世界书条目可搜索、展开和启停。
4. 编辑、重新生成、删除、导出、重置记忆和清空会话均有明确反馈。
5. 所有警告和确认均为站内组件，无浏览器原生弹窗。
6. 375px 与桌面宽度下均无水平溢出，固定输入区不遮挡消息。
7. 单元测试、组件测试、TypeScript 检查和生产构建全部通过。
